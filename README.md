# 共聚模拟实验室 · Copolymer Sequence Lab

在浏览器中探索二元共聚的单体序列、组成漂移和竞聚率。**无需安装、无需后端、可离线运行**，默认浅色，支持深色切换。界面与同作者的 [free-chain / FJC](https://github.com/dsadx-lxy/free-chain) 项目统一。

## 使用

在 [Releases](https://github.com/dsadx-lxy/copolymer-web/releases) 下载 `copolymer-lab-v2.0.0-offline.zip`，解压后用现代 Edge、Chrome 或 Firefox 打开 `index.html`。也可以下载本仓库的全部源码，直接打开根目录的 `index.html`。

运行不需要联网。数据计算、参数拟合均在浏览器本机完成；参考文献链接只有点击时访问网络。浏览器允许时，主题偏好保存在本地存储。

## 功能

- 二元共聚终端模型：调整竞聚率、投料比例、单体数、目标转化率及随机种子。
- 显示单链序列、剩余池组成、累计组成和窗口新增组成。
- 自定义统计窗口、早中晚阶段，统计连续同类单体段长度。
- 多次独立重复、均值及样本标准差（SD）带、逐点有效重复数。
- 保存六组实验对照并叠加曲线。
- 固定组成下与 Mayo–Lewis 方程及几何段长分布比较。
- 竞聚率网格扫描、多投料/多转化率观测数据的竞聚率拟合。
- 单活性链 SSA 时间模式，输入四个增长速率常数及浓度。
- JSON、CSV、SVG、PNG 导出；CSV 观测及 JSON 参数导入。
- Web Worker 计算与兼容回退，不使用外部 CDN 或 AI API。

## 快速演示

1. 以“无末端偏好”运行并保存对照。
2. 切换“交替倾向”，观察连续同类段的变化。
3. 切换“A优先消耗”，比较剩余池与聚合物组成漂移。
4. 改变初始投料比例，查看不同阶段统计。
5. 在反推区生成教学观测，验证拟合流程；再导入独立观测数据。

## 模型与限制

`r1 = kAA/kAB`，`r2 = kBB/kBA`；下标依次表示链末端和新加入单体。序列抽样模式每步加入一个单体并更新有限单体池，以转化率而非秒为横轴。

每次重复是一条链在一个独立单体池中的增长，**不是同一反应器中的多链竞争**。忽略引发、终止、链转移、扩散与倒数第二单元效应；不输出真实分子量分布，也不直接预测材料性能。长同类段倾向不等于保证得到完整二嵌段聚合物。

SSA 时间模式描述固定体积、给定浓度与速率常数下的单个已有活性链端，第一个单元在 t=0 初始化。它不代表完整自由基反应器动力学。

竞聚率反推使用准稳态终端方程的数值积分和无权最小二乘，搜索范围为 0.01—100，不识别严格零竞聚率。近优粗网格范围**不是置信区间**；教学合成数据及其他模拟数据不能称为真实实验验证。

输入观测 CSV：

```csv
f0,X,FA
0.2,0.2,0.3
0.5,0.2,0.6
0.8,0.2,0.9
```

三列依次为初始 A 摩尔分数、总转化率、累计聚合物 A 摩尔分数（0—1）。以上仅演示文件格式，不能作为实际体系的参数依据。至少三行、至少两种投料比例；数据必须满足物料守恒。

## 开发与测试

运行软件没有依赖。维护源码推荐 Node.js 26；也支持 22.22.2+（22 系列）或 24.15.0+（24 系列）。DOM 测试使用 jsdom。

```sh
npm ci
npm run build
npm test
```

| 文件 | 作用 |
|---|---|
| `index.html` | 已构建的独立离线应用 |
| `index.template.html` | 页面模板 |
| `model.js` | 随机序列及单链 SSA 内核 |
| `analytics.js` | 理论、统计与拟合 |
| `app.js` / `extensions.js` | 基础及高级交互 |
| `fjc-*.css` / `fjc-theme.js` | FJC 界面角色与主题 |
| `build.cjs` | 将源文件内嵌至独立 HTML |
| `test*.cjs` | 模型、计算控制、分析与 DOM 集成验证 |

已验证物料守恒、种子复现、边界条件、理论一致性、参数恢复及 DOM 工作流。**真实浏览器的视觉、窄屏、下载和原生 Worker 行为尚未完成全面实测**，DOM 测试不替代这些验收。欢迎通过 [Issues](https://github.com/dsadx-lxy/copolymer-web/issues) 提交浏览器版本与复现步骤。
